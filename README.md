### 1. DriveX

**SDV 차량 데이터 기반 FMS · 전사 차량 생애주기 관리**

- **기간:** 2026.06 – 2026.08
- **형태:** KT AIVLE School 팀 프로젝트 · 클라우드 PoC
- **역할:** 서비스 전략·기획 / 클라우드·인프라 / UX·UI 및 풀스택 개발 참여
- **활용 기술:** AWS S3, API Gateway, Lambda, RDS, Bedrock, FastAPI

차량 상태와 정비 이력이 분산되어 있으면 전체 운영 차량 중 우선 조치 대상을 판단하기 어렵습니다. DTC·주행거리·배터리·브레이크 상태와 정비 이력을 연결해 **위험 차량 조회 → 상세 진단 → 정비 요청**으로 이어지는 FMS를 기획했습니다.

**담당한 일**

- 서비스 요구와 차량 운영·정비 흐름을 정리하고 화면 구성에 참여했습니다.
- AWS 인프라와 FastAPI 기반 API·DB 연동을 담당했습니다.
- 연결 오류를 로그와 네트워크·보안 설정 점검으로 보완했습니다.
- Health Score 기반 판단과 생성형 AI의 설명 역할을 구분했습니다.

**결과:** 가공·공공 데이터로 상태 판단부터 API와 화면 제공까지 연결한 PoC를 구현했습니다. Big Project에서 **팀 Self-Motivation상**을 수상했습니다. 실제 SDV 차량 직접 연동과 운영 비용 절감 실적은 검증 범위에 포함하지 않았습니다.

### 2. 요근방

**나만의 건강한 한 끼 AI 서비스**

- **기간:** 2026.07 – 2026.08
- **형태:** 요기요 × 한국오라클 AI 해커톤 · 팀 MVP
- **역할:** 팀장·PM / 사용자 시나리오·데이터 정의·추천 로직 설계
- **팀 활용 기술:** FastAPI, OCI GenAI, Oracle DB

주문 이력만으로 반영하기 어려운 현재의 식사 의도·건강 목표·알레르기·예산을 추천 조건으로 정의했습니다. **자연어 요청 → 조건 해석 → 후보 조회·선정 → 추천 결과**로 이어지는 서비스를 팀과 함께 구성했습니다.

**담당한 일**

- 사용자 시나리오와 프로필·메뉴 데이터 항목을 정의했습니다.
- LLM의 자연어 해석과 DB·규칙 기반 후보 선정의 역할을 나누고 추천 로직을 설계했습니다.
- 필수 제외 조건과 선호에 따른 순위 기준을 구분했습니다.
- 개발자와 입출력 명세·일정을 조율하고 OCI 학습자료를 정리해 공유했습니다.

**결과:** 대화 입력부터 추천 결과까지 연결한 팀 MVP를 구성하고 **AI 해커톤 본선에 참가**했습니다. 주문·피드백 이력과 외부 데이터 연동, 일부 점수 로직의 보완은 후속 개발 범위로 구분했습니다.

[서비스 아키텍처](assets/yogeun-architecture.webp) · [웹 상세 보기](https://haileyk0022-star.github.io/portfolio_Hyein/#yogeun)

### 3. D-Curb Guardian

**생활물류 위험 분석 · 정책 의사결정 지원**

- **분석 범위:** 대전 5개 자치구 · 82개 행정동
- **역할:** 행정동 데이터 분석·대시보드 구현 참여
- **팀 산출물:** 위험도 지도, 지역 비교, 역할별 현장·정책 검토 화면

생활물류 위험 분석 결과를 행정동 단위로 정리하고, 지도와 순위 비교 화면으로 연결하는 데 참여했습니다. **지역 데이터 → 위험 비교 → 정책 검토** 흐름을 통해 담당자가 지역별 차이를 살펴볼 수 있도록 구성했습니다.

**담당한 일과 산출물**

- 대전 82개 행정동의 데이터 분석과 대시보드 구현에 참여했습니다.
- 팀은 지자체 관리자·물류기업·배송기사의 역할에 따른 화면을 구성했습니다.
- 팀 산출물에는 현장하역 지도, 데이터 신뢰도·수집 현황, 정책 What-if 화면이 포함됩니다.

정책 검토를 지원하는 분석·화면 산출물이며, 실제 정책 도입이나 사고 감소를 입증한 결과는 아닙니다.

### 4. 스마트 안전운전 보조 시스템

**운전자 상태 감지 · 통신 · 경고 출력**

- **기간:** 2024.09 – 2024.11
- **형태:** 동아대학교 캡스톤디자인 · 팀 프로젝트
- **역할:** 회로 구축·시스템 개발·문서화 / OpenCV 상태 판별·보드 연동 참여
- **팀 활용 기술:** OpenCV, Raspberry Pi, ATmega128, UART

운전자의 졸음·음주 상태를 감지하고 경고를 제공하는 보조 시스템입니다. 영상 분석·센서 입력·보드 간 통신·출력 제어를 하나의 동작 흐름으로 연결했습니다.

**담당한 일**

- 회로 구축과 시스템 개발, 문서화를 담당했습니다.
- OpenCV 기반 상태 판별과 제어 보드 연동에 참여했습니다.
- 영상 처리와 제어를 분리하고 시간 누적 판단을 적용해 순간적인 인식 변화를 구분했습니다.
- UART 통신과 LED·부저·모터 출력을 연결해 동작을 점검했습니다.

**결과:** 실물 경고 출력과 운전 기록 시각화를 연결했습니다. **2024 DA-LINC 캡스톤디자인 경진대회 팀 은상**을 수상했으며, **「연령 맞춤형 졸음 운전 보조 시스템」을 공동 출원**했습니다.

- 출원번호: **10-2025-0002927**
- 확인 범위: 프로토타입의 감지·통신·경고 기능 연동

### 5. Bon Appétit

**고객 공간을 활용하는 홈파티 서비스 기획**

- **형태:** ILAC International College · 캐나다 교육 과정 팀 프로젝트
- **역할:** 시장 조사·경쟁 분석·마케팅 전략 수립
- **산출물:** 서비스 제안, 브랜드 메시지, SNS 홍보 콘텐츠·운영 계획

행사 준비에 필요한 셰프·바텐더·DJ를 개별적으로 탐색하고 조율해야 하는 불편을 분석했습니다. 자체 공간이 없다는 제약을 고려해 **고객의 공간에 전문가와 식재료·장비를 제공하는 방식**을 제안했습니다.

**담당한 일**

- 고객 페르소나와 경쟁 서비스의 제공 범위를 분석했습니다.
- 행사 규모와 예산에 맞는 서비스 차별화 방향을 정리했습니다.
- 서비스 메시지를 홍보 콘텐츠와 마케팅 운영 계획으로 구체화했습니다.

교육 과정의 서비스 기획 프로젝트이며, 상용 출시나 매출 실적으로 제시하지 않습니다.
